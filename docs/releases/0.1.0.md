# Lunaria 0.1.0 — Keep your inspiration in sight

Put your references above the wallpaper, arrange them with **Ctrl+Alt+L**, and get back to work. Need them beside another app? Your board can now float above it.

Since 0.0.2, Lunaria adds floating placement, background image loading, original-image downloads, and a new botanical icon.

## Keep references where you need them

Press **Ctrl+Alt+Shift+L** to switch between the desktop and floating above applications. You can also choose **Float above apps** or **Return to desktop** from the tray menu.

Editing and placement work independently. Leave editing to let clicks pass through images to the app underneath. Floating edit mode stays open when you switch apps; returning to the desktop behind a maximized app ends editing.

## Keep arranging while images load

Imports now run one at a time in the background, so you can keep moving and arranging your board. Lunaria uses smaller display copies to reduce steady memory use, while keeping your imported originals unchanged.

Large AVIF files can still take several seconds. A loading hint and notification make slow imports visible. Enlarged display copies may look softer; the stored original keeps its full resolution.

## Take an original with you

Right-click an image in edit mode and choose **Download** to save its original file in Downloads. Existing files are never replaced.

Left-clicking an image now brings it to the front. Images also keep their default size when imported. Edit mode opens and closes with a short transition, and leaving it no longer leaves a stale desktop frame.

## A botanical mark

Lunaria now uses a seedless overlapping-pods icon in the notification area and on the executable, inspired by its botanical namesake.

## Download and update

**Windows x64 · Portable · No additional application runtime or image codec installation required**

Quit the older Lunaria through its notification-area menu, extract `Lunaria-0.1.0-windows-x64.zip`, and run `Lunaria/Lunaria.exe`. Your saved board stays in `%LOCALAPPDATA%\Lunaria`; keep that folder together when backing it up.

Or install with [Scoop](https://scoop.sh):

```powershell
scoop bucket add lunaria https://github.com/nekoium/Lunaria
scoop install lunaria/lunaria
```

This is the project's own bucket, with a Start menu shortcut and a `lunaria` command. For future updates, quit Lunaria and run `scoop update lunaria`.

The ZIP includes the executable, README, MIT license, and third-party notices. A `.sha256` file accompanies the download. The executable is unsigned.

## Before you start

Lunaria currently supports the primary monitor only, with fixed shortcuts and no automatic startup. Desktop placement can darken partially transparent images on newer Windows desktop layouts; floating placement and editing preserve per-pixel transparency. Visibility over exclusive fullscreen apps or other topmost windows is not guaranteed.

Images and boards stay local. See the [README](https://github.com/nekoium/Lunaria/blob/0.1.0/README.md) for controls, storage, and current limits.
