# Lunaria 0.1.1 — Your board, on your schedule

Keep your images close when you need them, and tuck them away when you don't. Lunaria can now hide your board for a while and bring it back when you sign in.

Since 0.1.0, Lunaria adds **Hide Lunaria**, optional **Start at login**, and installation through the shared **nekoium** Scoop bucket.

## Take a break from your board

Right-click the notification-area icon and check **Hide Lunaria**. Your images disappear, and editing ends. Uncheck it to return to your previous desktop or floating placement, outside edit mode.

Your images and arrangement stay intact. While hidden, image import, editing, and placement controls are disabled; the existing shortcuts leave the board hidden. Hiding lasts until you uncheck it or restart Lunaria.

## Bring your board back at login

Choose **Start at login** from the tray menu to restore your saved board when you sign in to Windows. It starts in desktop normal mode, without opening the editor. Automatic startup is off by default and needs no administrator rights.

A check mark means the startup entry exists. Select it again to remove the entry. If Windows has disabled it, the menu shows **Start at login (Disabled in Windows)**; re-enable Lunaria in **Task Manager → Startup apps** to allow launch.

The entry points to the executable's current location. Turn it off before moving or removing a portable copy, then run the new copy and enable it again.

## Download and update

**Windows x64 · Portable · No additional application runtime or image codec installation required**

Quit the older Lunaria through its notification-area menu, extract `Lunaria-0.1.1-windows-x64.zip`, and run `Lunaria/Lunaria.exe`. Your saved board stays in `%LOCALAPPDATA%\Lunaria`; keep that folder together when backing it up.

Or install with [Scoop](https://scoop.sh):

```powershell
scoop bucket add nekoium https://github.com/nekoium/scoop-bucket
scoop install nekoium/lunaria
```

The shared **nekoium** bucket provides a Start menu shortcut and a `lunaria` command. Existing installations using the original `lunaria` bucket continue to update without migration. To update, quit Lunaria and run `scoop update lunaria`.

The ZIP includes the executable, README, MIT license, and third-party notices. A `.sha256` file accompanies the download. The executable is unsigned.

## Before you start

Lunaria currently supports the primary monitor only, with fixed shortcuts. Desktop placement can darken partially transparent images on newer Windows desktop layouts; floating placement and editing preserve per-pixel transparency. Visibility over exclusive fullscreen apps or other topmost windows is not guaranteed.

Images and boards stay local. See the [README](https://github.com/nekoium/Lunaria/blob/0.1.1/README.md) for controls, storage, and current limits.
